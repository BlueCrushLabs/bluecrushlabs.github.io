## Analysis Tools

### Multi-Purpose Analysis

#### <a href="https://www.virustotal.com/" target="_blank" rel="noopener noreferrer">VirusTotal</a>

Multi-purpose threat intelligence and analysis platform for files, URLs, domains, IP addresses, and hashes.

#### <a href="https://capesandbox.com/" target="_blank" rel="noopener noreferrer">CAPE Sandbox</a>

Automated malware analysis sandbox focused on behavioral analysis, unpacking, payload extraction, and identifying malicious capabilities.

#### <a href="https://www.any.run/" target="_blank" rel="noopener noreferrer">ANY.RUN</a>

Interactive sandbox for analyzing malware, URLs, network activity, processes, and other artifacts in real time.

#### <a href="https://www.hybrid-analysis.com/" target="_blank" rel="noopener noreferrer">Hybrid Analysis</a>

Automated malware analysis platform providing behavioral reports, indicators, network activity, and threat intelligence.
